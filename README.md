# Нерезкое маскирование (ЛР 4, вариант 10)

Нужен .NET SDK 10.0+.

## Запуск

```bash
dotnet run -c Release
```

## Работа с приложением

1. **Открыть...** — выбрать изображение (`png`, `jpg`, `jpeg`, `bmp`, `webp`), например `../test_images/palace.jpg`.
   Файл читается асинхронно, после загрузки он появится слева («Исходное изображение»), а в строке состояния — его размер.
2. Задать параметры (таблица ниже). Для заметного эффекта: k = 1.5–3, σ = 2–4.
3. **Обработать** — изображение делится на полосы, которые обрабатываются пулом потоков.
   Прогресс‑бар и надпись «Собрано фрагментов: N из M» показывают ход работы; результат появится справа.
   В журнале внизу — время обработки, распределение фрагментов по потокам и число оставшихся рабочих потоков (должно быть 0).
4. **Отмена** (во время обработки, чтения или записи) — операция прерывается, частичный результат отбрасывается,
   в журнале появится «частичный результат отброшен». Чтобы успеть отменить, возьмите большое изображение
   (`../test_images/palace_big.jpg`), σ = 6–10 и 1–2 потока.
5. **Сохранить...** — выбрать путь (по умолчанию `<имя>_sharp.png`). Запись асинхронная; при отмене
   временный файл удаляется.

Во время операции параметры и кнопки, кроме **Отмена**, заблокированы.

Чтобы сравнить скорость, повторите шаг 3 с разным значением «Потоков в пуле» (1, 2, 4, 8…) и сравните время в журнале.

| Параметр | По умолчанию | Диапазон |
|---|---|---|
| Коэффициент k | 1.5 | 0.1–5 |
| σ размытия | 2.0 | 0.5–10 |
| Порог | 0 | 0–64 |
| Потоков в пуле | число ядер | 1–64 |
| Высота полосы | 32 | 4–1024 |
